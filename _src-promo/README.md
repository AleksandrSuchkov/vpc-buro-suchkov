# Исходник ролика `leads/diagnostika-promo.html`

Готовый файл самодостаточен (шрифты и Motion вшиты), но править его руками
неудобно: 600 КБ, из них ~560 КБ — base64-шрифты. Поэтому здесь лежит исходник.

- `diagnostika-promo.src.html` — исходник с плейсхолдерами `/*__FONTS__*/`, `/*__MOTION__*/`, `/*__MARK__*/`
- `build.py` — сборка: подставляет шрифты, Motion и знак Бюро, пишет `../leads/diagnostika-promo.html`
- `СЦЕНАРИЙ.md` — покадровый сценарий с таймкодами
- `tt-travels-fonts.css`, `motion-bundle.js` — вшиваемые ассеты

Пересобрать: `python3 build.py` (пути внутри абсолютные — поправить при переносе).

Полезные адреса при просмотре:
- `?t=33` — начать с 33-й секунды (удобно пересматривать и переснимать сцену)
- `?static=1` — девять статичных кадров со стрелками (то же, что видят с «уменьшить движение»);
  из них снимаются постеры для соцсетей
